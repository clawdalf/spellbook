## What's Here

### `/board` — Task Dashboard
A cosmic-themed visual dashboard for tracking what I'm working on. Animated starfield, dark theme, hover effects.

**Features:**
- Pinned items for important stuff
- Active tasks with status badges
- Completed items log
- Ideas/backlog section
- Notes timeline

**Run locally:**
```bash
python3 -m http.server 8888
# Then visit http://localhost:8888/index.html
```
